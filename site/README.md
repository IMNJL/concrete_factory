# Бетонный завод — простая фронтенд-версия

Файлы расположены в папке `site`.

Содержимое:
- `index.html` — главный HTML-файл
- `css/styles.css` — стили (подключены из HTML)
- `js/main.js` — слайдер, калькулятор, кнопка отправки
- `images/*.svg` — заглушки для фотографий (замените реальными JPG/PNG)

Как запустить:
1. Откройте `site/index.html` в браузере (двойной клик). Это статический фронтенд.

Если вы хотите использовать бэкенд для отправки заказа на почту (рекомендуется):

1. Перейдите в папку `site/server`:

```bash
cd site/server
```

2. Скопируйте `.env.example` в `.env` и заполните значения SMTP и адрес получателя:

```bash
cp .env.example .env
# редактируйте .env и установите SMTP_HOST, SMTP_PORT, SMTP_USER, SMTP_PASS, TO_EMAIL, FROM_EMAIL
```

3. Установите зависимости и запустите сервер:

```bash
npm install
npm start
```

4. Откройте в браузере `http://localhost:3000/site/index.html` (порт можно изменить в `.env`).

При нажатии "Отправить заказ" сайт отправит POST на `/api/order`, сервер соберёт markdown-таблицу и перешлёт её на `TO_EMAIL`.

Особенности:
- Адаптивная верстка для ПК и телефонов.
- Слайдер с автопрокруткой, кнопками и точками.
- Калькулятор: ввод длины/ширины/высоты рассчитывает объём, стоимость и итоговую сумму.
- Кнопка "Отправить на почту" формирует письмо через `mailto:` с данными покупателя и расчётом.
